Query Information

SQL Query:

SELECT
    host,
    region,
    AVG("user") as avg_user,
    AVG(idle) as avg_idle,
    AVG(system) as avg_system
FROM prod.cpu
GROUP BY host, region
ORDER BY avg_user DESC
