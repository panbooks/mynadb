# v0.9.1 — Dashboard and Time-Bucket Query Fixes

This maintenance release fixes dashboard response handling and distributed InfluxQL time-bucket reaggregation. Its full delta also includes intervening admin/source refactoring, documentation expansion, Chinese translation, and documentation deployment work.

- **Source commit:** [`837839e`](https://github.com/panbooks/mynadb/commit/837839e3abbff5f9221f6fd27a9a8df89e0f6c1b)
- **Changes since:** `v0.9.0` — **14 commits**, including merged branch commits where present
- **Historical development period:** February 14, 2026 – July 14, 2026

## What's included

### Dashboard response handling

- Accept both bare row arrays and wrapped query responses shaped as `{ success, data, rows, error }`.
- Extract the row array from wrapped responses and propagate an explicit query error when `success` is false.
- Refresh dashboard JavaScript cache-busting versions so browsers request the updated assets.

### Distributed time-bucket queries

- Resolve `GROUP BY time(interval)` expressions to the actual `time` bucket column returned by Data nodes instead of treating `time(1m)` as a literal column name.
- Recognize case/spacing variants and offset arguments in the expression-detection helper.
- Add a unit test for expression detection; this is not a complete distributed-query regression suite.

### Other changes since v0.9.0

- Extract shared admin response types/helpers and Data-node forwarding logic; simplify duplicated or deeply nested source code.
- Align the Router test with the existing rule that suspect nodes can remain queryable.
- Expand feature/admin/cluster documentation and fix outdated references.
- Add Chinese portal translation, a GitHub Pages workflow, and project-relative portal links.
- Add architecture analysis, Iceberg/OTLP proposal documentation, and Claude development commands/skills.
- Add development API documentation alongside the dashboard/aggregation fix.

## Compatibility and upgrade notes

- The dashboard accepts both older bare arrays and wrapped row responses; no query-response format migration is required for that client change.
- This tag's 14-commit delta includes more than the final dashboard fix. Review the comparison if upgrading from v0.9.0.
- Architecture/proposal documents describe designs and gaps; they do not mean all proposed functionality was implemented.
- Cargo remains `mynadb 0.1.0`. Use the release tag or source SHA to identify this snapshot.

## Important limitations

- Recognition of `time(...)` variants in the helper is not evidence that every offset, fill mode, or distributed aggregation is validated end to end.
- The existing Iceberg JSON-manifest, continuous-aggregate, downsampling-rewrite, and Router MySQL limitations are not removed by this patch.
- Source and the actual patch were reviewed; this historical tag was not separately rebuilt or runtime-tested for these notes.
