Research the database topic: $ARGUMENTS

Steps:
1. Search the web for the latest information (2025-2026) about the topic.
2. If it's a specific database: find its architecture, key features, performance benchmarks, and how it compares to MynaDB.
3. If it's a feature/technology: find which databases implement it, how they do it, and what the state of the art is.
4. Check the MynaDB codebase for any existing related implementation.
5. Present findings in a structured table format with:
   - Feature comparison matrix
   - Architecture differences
   - What MynaDB can learn / adopt
   - Relevant links and sources

Always include Sources with URLs at the end.
