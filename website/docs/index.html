Stats Service Documentation

Welcome to the Stats Service documentation. Stats Service is a high-performance time series database built with Rust, Apache DataFusion, and Parquet for modern infrastructure monitoring and analytics.

💡 New to Stats Service?

Start with our Quick Start Guide to get up and running in minutes.

What is Stats Service?

Stats Service is a time series database designed for high-throughput ingestion and fast analytical queries. It combines the best of modern data infrastructure:

  • InfluxDB Line Protocol - Compatible write API for easy migration
  • Apache Parquet - Columnar storage for excellent compression and query performance
  • Apache DataFusion - Full SQL query support with advanced analytics
  • Apache Arrow Flight - High-performance gRPC streaming for data transfer
  • Rust - Memory-safe, zero-cost abstractions for maximum performance

Key Features

🔥

High Performance

Written in Rust with zero-copy deserialization for maximum throughput and low latency.

🔎

SQL Queries

Full SQL support including JOINs, aggregations, window functions, and CTEs.

🗃

Columnar Storage

Parquet format provides up to 90% compression with excellent query performance.

🔌

InfluxDB Compatible

Drop-in replacement for InfluxDB write API for seamless migration.

Quick Example

bash 
# Write metrics using InfluxDB Line Protocol
curl -X POST http://localhost:7000/write/mydb -d '
cpu,host=server01,region=us-west usage=75.5,temp=45
cpu,host=server02,region=us-east usage=82.3,temp=50
memory,host=server01 used=16.5,total=32.0
'

# Flush data to disk
curl -X POST http://localhost:7000/flush

# Query with SQL
curl 'http://localhost:7000/query/mydb' \
  -d 'SELECT host, AVG(usage) as avg_cpu FROM cpu GROUP BY host'
